# NBM Studio

NBM Studio는 경제·주식 콘텐츠 제작을 위한 Electron 기반 데스크톱 편집기입니다.

## 현재 단계

- Alpha 2 기반 저장소 초기화
- Electron 데스크톱 실행 구조
- 금융 인포그래픽 편집기 확장 예정

## 예정 기능

- Shift 다중 선택
- Ctrl+C / Ctrl+V
- 그룹 / 그룹 해제
- 레이어 패널
- 정렬 및 레이어 순서 변경
- 프로젝트 저장(`.nbm`)
- PNG / SVG 내보내기
- Undo / Redo

## 실행

```bash
npm install
npm start
```
